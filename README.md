🌟 Overview

មហាសិរី Network (MSN) Governance website provides stakeholders, shareholders, and internal teams with a clear visual presentation of the company’s governance framework. It ensures transparency, accountability, and streamlined strategic alignment from high-level shareholders down to daily operations.

🏛️ Organizational Structure

The hierarchy modeled in this platform follows a 3-tier system:

Shareholder Level (ម្ចាស់ភាគហ៊ុន / Convenience Level)

The ultimate decision-making body and ownership tier responsible for major policy approvals and strategic guidance.

Board of Directors (ក្រុមប្រឹក្សាភិបាល - Board Members)

Overlooks strategic planning and supervises 5 specialized departments:

🔍 នាយកដ្ឋានសវនកម្ម (Audit Department): Internal audits, compliance, and risk assessment.

🧭 នាយកដ្ឋានគ្រប់គ្រង និងដឹកនាំ (Management & Leadership Dept): Strategic policy execution and KPI tracking.

⚖️ នាយកដ្ឋានផ្នែកវិន័យ (Discipline Department): Workplace ethics, policy enforcement, and conflict resolution.

📈 នាយកដ្ឋានអភិវឌ្ឍន៍ និងហិរញ្ញវត្ថុ (Development & Finance Dept): Budget management and growth investments.

🎓 នាយកដ្ឋានបណ្តុះបណ្តាល (Training Department): Human capital enhancement and leadership training.

Executive Committee (គណៈកម្មាធិការប្រតិបត្តិ)

Handles daily operations, project execution, and converts board strategies into measurable outcomes.

✨ Key Features

Interactive Tree Diagram: Visual representation of organizational flow with interactive modal popups.

Khmer Typography Support: Integrated Google Fonts (Moul and Kantumruy Pro) tailored for clear readability.

Responsive Design: Fluid layout optimized for desktops, tablets, and mobile devices.

Modern UI: Styled with Tailwind CSS, glassmorphism UI elements, and gold/navy brand aesthetics.

🛠️ Tech Stack

HTML5: Semantic web structure.

Tailwind CSS: Utility-first styling (via CDN).

JavaScript (ES6+): Interactive modal dialogues and responsive navigation.

FontAwesome 6: Modern iconography.

Google Fonts: Custom typography (Moul, Kantumruy Pro).

🚀 Getting Started

Prerequisites

No build tools or node modules are required. Simply use any modern web browser (Chrome, Safari, Firefox, Edge).

Installation

Clone the repository:

git clone https://github.com/your-username/msn-governance.git


Navigate into the project folder:

cd msn-governance


Open index.html in your browser:

# On macOS
open index.html

# On Linux
xdg-open index.html

# Or simply double-click index.html in your file manager


📖 Usage

Navigation: Click on the top navigation bar to jump directly to specific sections.

Interactive Diagram: Click on any node inside the organizational diagram section to open a modal window containing full role descriptions.

Mobile Support: Use the hamburger menu icon at the top right when viewing on smaller screens.
